# MotionCaption 统一编辑器工作台设计

日期：2026-09-07

## 目标

以 MotionCaption 为唯一产品界面，保留其精品动效库，并迁入 CaptionForge 的视频、字幕、工程编辑和透明导出能力。界面不再分成独立“编辑器”和“组件实验室”；所有操作在一个工作台完成。

支持两条同等重要的使用路径：

1. 完全手工：空工程中挑选组件、编辑内容与时间、导出透明视频。
2. AI 编排：内置 LLM 或安装了组件 skill 的外部 Agent 选择现有组件并生成 JSON 序列；程序校验通过后直接覆盖当前全部动效。

视频和字幕均为可选输入。新工程默认 1920×1080、30fps、10 秒。

## 统一布局

采用可折叠四区布局：

- 顶部工具栏：载入视频、导入字幕、导入 Agent JSON、AI 编排、同步组件 Skill、打开工程、保存工程、工程设置和透明导出。工具栏保持单行紧凑高度，不放工程状态文字。
- 左侧特效栏：搜索框、列表内分类分割条和密集组件项。分类不使用下拉框，组件项不显示长说明。
- 中间视频栏：唯一合成画布；显示参考视频、动效和编辑覆盖层。
- 右侧属性栏：编辑所选组件的内容、位置、缩放、时间、轨道和 zIndex。
- 底部时间轴：只读字幕参考轨和多条可编辑动效轨。

左右栏可折叠。时间轴取消高度滑动条，改用顶部水平分隔线拖动高度；高度限制为 140px 至工作区高度的 60%，双击分隔线恢复默认高度。取消页面级“编辑器/组件实验室”切换。

## 画布

画布始终使用工程坐标系。默认预览透明棋盘，也可切换为当前 MotionCaption 深色背景；载入本地视频后还可切换为参考视频。三种背景只影响编辑预览，不能进入透明导出结果。

参考视频是可选对齐素材。视频文件、对象 URL 和本机路径不进入工程 JSON。

视频画布上方不保留单独状态栏。工程/参考视频状态和画布参数显示在画布底部控制条左侧，例如 `空工程 · 无参考视频 | 1920×1080 · 30fps`。播放/暂停按钮固定在控制条水平正中，时间和帧数右对齐；控制条常驻，鼠标经过时增强亮度，但不自动隐藏，也不占用工作区布局高度。时间轴画布裁剪播放头溢出，播放头停在末帧时不产生横向滚动条。

动效与视频在同一个画布中合成。编辑选择框属于独立覆盖层；组件实现和正式 Remotion 合成不持有鼠标状态。导出时不渲染选择框。

点击按 zIndex 和视觉顺序命中实例。标题与半环等同时间组件可分别选择、拖动和四角等比缩放。修改一个实例不能改变其他实例的 props。

## 特效添加与属性编辑

左侧单击组件后，立即使用注册表默认内容和默认变换在当前时间创建正式实例；新实例自动选中，右侧立即显示其属性。组件栏不保留单独的“添加到当前时间”按钮。实例立即进入画布和时间轴，不存在手工组件的草稿阶段。

右侧属性栏基于 EffectDefinition 生成字段。内容字段、位置、缩放、起止时间、轨道和 zIndex 均写回正式 `MotionProject.effects`。任何更新都需保持工程 Schema 有效，并限制在工程时长和画布边界内。

## AI 编排与 Agent JSON

AI 只编排已有组件，不生成新的视觉组件代码。左侧栏只展示组件库；顶部 `AI 编排` 按钮打开轻量弹窗，显示字幕数量、组件库版本、模型配置和可选风格要求。

内置 Agent 使用 OpenAI-compatible API。Base URL 和模型名可保存为普通设置；API Key 存入系统凭据库，不写入 localStorage、日志、工程 JSON 或错误信息。正式网络请求由 Tauri 原生命令或受控 sidecar 发出，前端不能读取明文 Key。请求层使用可替换 Provider，浏览器开发和自动测试使用假 Provider，不调用真实收费 API。

内置 Agent 输入当前字幕、画布参数、组件库版本、用户风格要求和组件选择摘要。它使用与外部 skill 同源的结构化 manifest；选定组件后再加载对应 reference，避免每次请求携带全部组件的完整说明。模型输出只按 strict JSON 解析，绝不执行其代码或命令。

首次输出出现硬错误时，程序把结构化错误反馈给 LLM，并自动修复一次。第二次仍失败则停止，显示错误，当前工程保持不变。零硬错误时直接原子覆盖当前 `project.effects`；软警告仅展示，不阻止导入。生成期间继续显示旧动效。

外部 Agent 可安装导出的组件 skill，自行生成同格式 JSON，再由顶部 `导入 Agent JSON` 入口载入。

程序导入 JSON 时依次执行 strict schema、组件与版本、字段类型、字幕来源、列表容量和排他冲突校验。全部通过后，确定性编译并原子覆盖当前 `project.effects`；无需草稿状态或二次确认。

校验失败时显示完整错误列表，当前工程保持不变。删除 `draftEffects`、`draftReview`、`applyDraft` 和 `discardDraft` 等持久草稿状态及其界面。

## 组件 Skill 生成与同步

`EffectDefinition` 及组件旁的 AI 元数据是组件能力的唯一来源。生成器产出：

- 根 `SKILL.md`：组件编号、适用场景和选择规则。
- `references/<组件ID>.md`：参数、类型、默认值、容量、限制和示例。
- 内置 Agent 使用的结构化 manifest。

生成文件提交到 Git 以便审查，但禁止直接编辑。`npm run generate:skill` 重建产物，`npm run check:skill` 检查注册表、元数据、references 和 manifest 是否一致。组件参数或行为改变时提升 `componentVersion`；组件库增删时提升 `libraryVersion`。Agent JSON 携带版本，程序拒绝不兼容输入。

由于新组件通常由 AI 直接生成代码，顶部提供 `同步组件 Skill`：

1. 扫描组件目录和 registry，识别新增、删除、版本与参数变化。
2. 从组件代码、Prop 类型和默认值提取可确定的结构信息。
3. 调用 LLM 起草适用场景、语义角色、容量、限制和示例。
4. 展示新增、修改、删除和无法判断项的预览。
5. 用户确认后更新 AI 元数据及全部 skill 产物，再运行一致性校验。
6. 任一步失败时保留旧 skill，不产生半更新状态。

未注册或 AI 元数据未确认的新组件可以手工使用，但不能进入 AI 编排候选。设置界面显示当前 skill/library 版本，并可导出最新版 skill 文件夹或 ZIP，供其他 Agent 工具安装。

## 时间轴

顶部保留只读字幕参考轨；下方每个正式组件实例是独立时间块。同场景组件可共享起止区间，但仍是可独立编辑的实例。

时间块支持选择、整体移动、调整起止边界和切换轨道。时间不得为负、越过工程末尾或产生零长度。

轨道较多时，轨道内容区纵向滚动；时间轴放大后，内容区横向滚动。时间标尺在纵向滚动时保持顶部可见，轨道名称在横向滚动时保持左侧可见。滚轮/滚动条不能改变工程数据。播放头、字幕和组件块共享同一时间比例。

时间轴右上角常驻缩小、放大和重置缩放按钮，视觉样式参考旧 CaptionForge。高度只能通过顶部拖拽分隔线调整，不显示高度 range 输入。

每条轨道左侧显示眼睛图标。关闭后只隐藏该轨道在编辑画布中的预览，不修改工程实例，也不影响透明导出；可见性属于编辑器状态。时间轴显示自适应时间刻度和当前播放头，绘制与缩放/横向滚动保持对齐，可参考旧 CaptionForge 的刻度步长和播放头方法。

所有可滚动控件使用统一深色主题滚动条，包括组件栏、属性栏、时间轴横纵区域和弹窗。滚动条保持细窄，轨道与滑块使用面板色，悬停使用主题强调色，不允许深色界面出现系统浅色滚动条。

## 工程持久化

工程保存为 strict `captionforge.project` JSON，包含画布参数、字幕和正式组件实例，不包含本地视频文件或路径。

打开工程时先检查 kind、版本和 Schema；失败返回可展示错误，并保证当前工程对象不变。

## 透明导出

透明导出只渲染正式组件，不包含参考视频、棋盘/深色预览背景、鼠标覆盖层或编辑器 UI。

浏览器 Web Renderer 已在真实验证中因 `t7-06` 丢失 SVG 半环而被否决。正式实现继续使用可替换 `RenderBackend`，下一候选为 Node/Remotion sidecar，优先透明 MOV。后端不支持或导出失败时明确报错，不静默降级为黑底或不透明视频。

## 验收

- 单页四区工作台可用；折叠侧栏、调整时间轴高度和双向滚动不造成页面溢出。
- 空工程无需视频或字幕即可添加、编辑、保存、打开和导出组件。
- 标题与半环同时显示，并可分别点击、拖动、缩放、编辑文字、时长、轨道和 zIndex。
- 棋盘、深色和参考视频预览可切换，均不进入透明导出。
- 字幕参考轨只读；多条动效轨可编辑，纵向和横向滚动正确。
- 每轨眼睛只控制编辑预览；时间刻度和播放头在缩放、横向滚动后仍准确。
- 所有滚动区域使用与深色主题一致的滚动条。
- 合法 Agent JSON 直接覆盖全部动效；非法 JSON 被拒绝且工程不变。
- 内置 AI 编排读取字幕并自动导入；首次硬错误自动修复一次，最终失败不改变工程。
- `同步组件 Skill` 能识别新增/变化组件，预览 AI 起草的元数据，并以原子方式更新生成物。
- 生成 skill、references 与内置 manifest 和 registry 保持版本一致；外部 Agent 生成的 JSON 可导入。
- T1、T2、T7 代表组件完成入口、中间、稳定和结束前四帧视觉检查，以及白/黑/彩底 Alpha 检查。
- 自动测试、类型检查、构建和真实浏览器交互验收全部通过。

## 非目标

- AI 编排不创建新的组件代码，只选择并参数化已注册、元数据已确认的组件。
- 同步组件 Skill 不静默批准 AI 推断的语义元数据。
- 不恢复低质量 CaptionForge 组件库。
- 不在本阶段测量 45 个组件的精确 DOM 边界；碰撞预警使用注册表声明的保守 planning footprint。
- 不让编辑预览背景进入成片。
