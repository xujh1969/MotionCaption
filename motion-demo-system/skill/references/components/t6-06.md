# t6-06 - 多步骤向上浮动递进时间线

- Component version: 1
- Use for: Iterative multi-step process with 2-4 steps.
- Avoid: Avoid unrelated prose, metrics, charts, and more than 4 steps.
- Motion feel: —
- Capacity: 2-4 items

## Editable content

Only the following keys may appear in `content`. All style and component layout properties are locked and must not be supplied by an Agent.

- `footerText`: text; required: yes; default: `"位置或时间还差一点，就重新循环"`; semantic role: body; constraints: none beyond the declared type.
- `steps`: array of objects { num: 序号 (string), t: 步骤文字 (string) }; required: yes; default: `[{"num":"01","t":"描述问题"},{"num":"02","t":"AI 改代码"},{"num":"03","t":"重新渲染"},{"num":"04","t":"打开看结果"}]`; semantic role: items; constraints: 2-4 items; all listed item fields are required strings.
- `titleText`: text; required: yes; default: `"AI 迭代调试 · 循环推进"`; semantic role: title; constraints: none beyond the declared type.

## Per-item timing (`at`)

Each item in `steps` carries a numeric `at` field — the item's appearance time in **seconds, relative to the scene's earliest cited cue start**. Items appear at their `at` time instead of the default even rhythm.

- **Every item that corresponds to one cited cue MUST get an `at`.** Compute it from the cue start times: `at = (cueStartMs − earliestCitedCueStartMs) / 1000`, rounded to 1 decimal. Include every cue you used in the scene's `sourceCueIds`.
- Worked example: a scene cites cues starting at 9800ms / 15600ms / 21400ms (earliest = 9800) and its steps rows visualize them → `at` values are `0`, `5.8`, `11.6`. The first item is `0`, and each later item appears exactly when its cue begins to be spoken.
- Omit `at` ONLY for an item that is a general summary not tied to any single cue (rare). Do NOT leave `at` out of items just to be safe, and do NOT invent evenly spaced values that no cue supports.
- `at` must be a number ≥ 0 (never a string, never negative, never beyond the scene duration). The example JSON below shows the field shape — replace the demo values with cue-derived ones.
