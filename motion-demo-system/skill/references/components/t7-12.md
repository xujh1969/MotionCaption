# t7-12 - 漏斗转化流程(分层梯形·两侧标注)

- Component version: 1
- Use for: Conversion funnels, marketing pipelines, or user journey decay shown as a layered funnel chart with side annotations.
- Avoid: Avoid processes without funnel semantics, timelines, charts of other shapes, and more than 5 layers.
- Motion feel: 漏斗层按数组顺序自上而下逐层生长（由窄扩宽+向下展开，约1s），层内文字、左侧阶段胶囊、右侧圆点/标题/说明依次淡入；多个用户图标从上方飘落汇入漏斗上口；完成后各层带 0.2~0.35 呼吸辉光（当前层 0.45）。
- Capacity: 2-5 items

## Editable content

Only the following keys may appear in `content`. All style and component layout properties are locked and must not be supplied by an Agent.

- `layers`: array of objects { innerText: 层内文字 (string), leftLabel: 左侧阶段 (string), rightDesc: 右侧说明 (string), rightTitle: 右侧标题 (string) }; required: yes; default: `[{"innerText":"有效触达","leftLabel":"阶段一","rightDesc":"场景内容与达人测评覆盖目标人群，形成品牌搜索。","rightTitle":"认知扩圈"},{"innerText":"高意向访问","leftLabel":"阶段二","rightDesc":"官网与电商承接评测流量，推动预约、试用和加购。","rightTitle":"兴趣沉淀"},{"innerText":"试用申请","leftLabel":"阶段三","rightDesc":"在线试用与客服跟进推动申请提交。","rightTitle":"试用转化"},{"innerText":"成交订单","leftLabel":"阶段四","rightDesc":"直播、门店与企业试用推动首购，CRM 承接复购。","rightTitle":"成交复购"}]`; semantic role: items; constraints: 2-5 items; all listed item fields are required strings.

## Per-item timing (`at`)

Each item in `layers` carries a numeric `at` field — the item's appearance time in **seconds, relative to the scene's earliest cited cue start**. Items appear at their `at` time instead of the default even rhythm.

- **Every item that corresponds to one cited cue MUST get an `at`.** Compute it from the cue start times: `at = (cueStartMs − earliestCitedCueStartMs) / 1000`, rounded to 1 decimal. Include every cue you used in the scene's `sourceCueIds`.
- Worked example: a scene cites cues starting at 9800ms / 15600ms / 21400ms (earliest = 9800) and its layers rows visualize them → `at` values are `0`, `5.8`, `11.6`. The first item is `0`, and each later item appears exactly when its cue begins to be spoken.
- Omit `at` ONLY for an item that is a general summary not tied to any single cue (rare). Do NOT leave `at` out of items just to be safe, and do NOT invent evenly spaced values that no cue supports.
- `at` must be a number ≥ 0 (never a string, never negative, never beyond the scene duration). The example JSON below shows the field shape — replace the demo values with cue-derived ones.
