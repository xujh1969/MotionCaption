# t5-13 - 纵向步骤卡片(标题+选项依次高亮·数组扩展)

- Component version: 1
- Use for: Modeling steps, staged breakdowns, or progressive plans shown as stacked step cards with a two-line headline, placed at the left safe zone.
- Avoid: Avoid more than 5 cards, parallel unordered items, and long titles beyond one line.
- Motion feel: 主标题两行错位淡入（亮度 0.4→1，约 500ms，先于首卡 0.9s）；卡片按数组顺序依次点亮（300ms：深蓝底浮现+青边框+序号变蓝+标题变白+左侧指示点微光），每个 at 独立控制；**点亮后回落为已完成态**（弱蓝底、保留较低亮度、不回透明），同一时刻只有一张激活；结尾 600ms 卡片从上到下依次熄灭、标题同步淡出。
- Capacity: 2-5 items

- `items`: array of objects { num: 序号 (string), title: 步骤标题 (string) }; required: yes; default: `[{"num":"00","title":"基础体块"},{"num":"01","title":"核心结构"},{"num":"02","title":"形态细化"}]`; semantic role: items; constraints: 2-5 items; all listed item fields are required strings.
- `titleLine1`: text; required: yes; default: `"先做结构"`; semantic role: title; constraints: none beyond the declared type.
- `titleLine2`: text; required: yes; default: `"再做细节"`; semantic role: title; constraints: none beyond the declared type.
