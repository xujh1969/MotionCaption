# t7-09 - 环形占比饼图(分段依次生长)

- Component version: 1
- Use for: Composition, share, or resource allocation with 2-4 ring segments; percentages should total 100.
- Avoid: Avoid large datasets, precision analysis, time series, and more than 4 segments.
- Motion feel: 环形分段按数组顺序依次生长填充（每段约 550ms），中心数字同步计数跳变，图例随之点亮。
- Capacity: 2-4 items

## Editable content

Only the following keys may appear in `content`. All style and component layout properties are locked and must not be supplied by an Agent.

- `centerDesc`: text; required: yes; default: `"资源占比"`; semantic role: body; constraints: none beyond the declared type.
- `centerNum`: number; required: yes; default: `100`; semantic role: metric; constraints: minimum 0; maximum 100000.
- `centerUnit`: text; required: yes; default: `"%"`; semantic role: label; constraints: none beyond the declared type.
- `items`: array of objects { label: 分段名称 (string), percent: 占比数值 (string) }; required: yes; default: `[{"label":"算力","percent":"45"},{"label":"存储","percent":"35"},{"label":"网络","percent":"20"}]`; semantic role: items; constraints: 2-4 items; all listed item fields are required strings.

## Per-item timing (`at`)

Each item in `items` carries a numeric `at` field — the item's appearance time in **seconds, relative to the scene's earliest cited cue start**. Items appear at their `at` time instead of the default even rhythm.

- **Every item that corresponds to one cited cue MUST get an `at`.** Compute it from the cue start times: `at = (cueStartMs − earliestCitedCueStartMs) / 1000`, rounded to 1 decimal. Include every cue you used in the scene's `sourceCueIds`.
- Worked example: a scene cites cues starting at 9800ms / 15600ms / 21400ms (earliest = 9800) and its items rows visualize them → `at` values are `0`, `5.8`, `11.6`. The first item is `0`, and each later item appears exactly when its cue begins to be spoken.
- Omit `at` ONLY for an item that is a general summary not tied to any single cue (rare). Do NOT leave `at` out of items just to be safe, and do NOT invent evenly spaced values that no cue supports.
- `at` must be a number ≥ 0 (never a string, never negative, never beyond the scene duration). The example JSON below shows the field shape — replace the demo values with cue-derived ones.
