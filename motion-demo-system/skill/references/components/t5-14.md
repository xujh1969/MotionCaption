# t5-14 - 指标结果面板(标题+纵向指标卡片·数组依次入场)

- Component version: 1
- Use for: Benchmark results, render metrics, performance stats, or success reports shown as stacked metric cards with count-up numbers, placed at the left safe zone.
- Avoid: Avoid more than 6 cards, non-numeric values, and dense multi-column metrics.
- Motion feel: 小标题先淡入，200ms 后两行主标题先后淡入（约 550ms）；指标卡片按数组顺序逐张上浮淡入（400ms），每个 at 独立控制；**数字从 0 平滑计数到目标值**（与入场同步，支持千分位/小数/后缀）；已入场的保持高亮（淡绿底+顶部描边色+微光）并轻微呼吸，末卡光效更明显作收尾强调；结尾 600ms 卡片自下而上逆序淡出上浮、标题最后淡出。
- Capacity: 2-6 items

## Editable content

Only the following keys may appear in `content`. All style and component layout properties are locked and must not be supplied by an Agent.

- `items`: array of objects { label: 指标名称 (string), value: 数值(支持千分位/小数/后缀) (string) }; required: yes; default: `[{"label":"网格数","value":"47"},{"label":"三角面","value":"28,858"},{"label":"绘制调用","value":"48"}]`; semantic role: items; constraints: 2-6 items; all listed item fields are required strings.
- `subTitleText`: text; required: yes; default: `"最终浏览器指标"`; semantic role: title; constraints: none beyond the declared type.
- `titleLine1`: text; required: yes; default: `"测试完成"`; semantic role: title; constraints: none beyond the declared type.
- `titleLine2`: text; required: yes; default: `"可以使用"`; semantic role: title; constraints: none beyond the declared type.
