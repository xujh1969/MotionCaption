# t5-12 - 关键词标签组(主标题+胶囊标签依次点亮·数组扩展)

- Component version: 1
- Use for: Spoken keyword emphasis, module breakdowns, or technical term callouts shown as a two-line headline with pill tags, placed at the bottom safe zone.
- Avoid: Avoid more than 10 tags, very long tag labels beyond 6 characters, and using it as the main content block.
- Motion feel: 主标题两行先后错位亮起（亮度 0.3→1，约 600ms，先于首个标签 1s）；标签按数组顺序逐个点亮（约 320ms：深蓝填充浮现+文字提亮+青色边框微光），每个 at 独立控制可匹配口播关键词；**同一时刻只有一个标签处于激活态**——下一个点亮时上一个自动回落为未激活灰态（焦点跟随口播移动），最后一个保持到退场；激活期间呼吸微光（0.25~0.4）；结尾 500ms 标签逆序熄灭、标题同步降亮度。
- Capacity: 2-10 items

- `titleLine2`: text; required: yes; default: `"转换为建模目标"`; semantic role: title; constraints: none beyond the declared type.
