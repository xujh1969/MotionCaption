# t3-06 - 横向对比双列卡片组(正反对照)

- Component version: 1
- Use for: Two-sided comparison such as old vs new or plan A vs plan B, with 1-2 comparison groups and 2-3 bullet points per side.
- Avoid: Avoid single-sided lists, metrics without contrast, timelines, and more than 2 groups.
- Motion feel: 按「组」依次入场；组内左右两卡可分别设定出现时间（右卡 atB 留空时与左卡同步点亮），卡片上浮淡入，要点逐条上浮淡入跟进（间距由 staggerMs 控制），可跟着口播左右分开起落。
- Capacity: 1-2 items

## Editable content

Only the following keys may appear in `content`. All style and component layout properties are locked and must not be supplied by an Agent.

- `groups`: array of objects { pointsA: 左卡要点(|分隔) (string), pointsB: 右卡要点(|分隔) (string), titleA: 左卡标题 (string), titleB: 右卡标题 (string) }; required: yes; default: `[{"pointsA":"部署复杂|成本较高|扩展有限","pointsB":"开箱即用|成本更低|弹性扩展","titleA":"传统方案","titleB":"新方案"},{"pointsA":"单机运行|无容灾","pointsB":"集群部署|自动容灾","titleA":"方案一","titleB":"方案二"}]`; semantic role: items; constraints: 1-2 items; all listed item fields are required strings.
- `markA`: text; required: yes; default: `"✗"`; semantic role: label; constraints: none beyond the declared type.
- `markB`: text; required: yes; default: `"✓"`; semantic role: label; constraints: none beyond the declared type.

## Per-item timing (`at`)

Each item in `groups` carries a numeric `at` field — the item's appearance time in **seconds, relative to the scene's earliest cited cue start**. Items appear at their `at` time instead of the default even rhythm.

- **Every item that corresponds to one cited cue MUST get an `at`.** Compute it from the cue start times: `at = (cueStartMs − earliestCitedCueStartMs) / 1000`, rounded to 1 decimal. Include every cue you used in the scene's `sourceCueIds`.
- Worked example: a scene cites cues starting at 9800ms / 15600ms / 21400ms (earliest = 9800) and its groups rows visualize them → `at` values are `0`, `5.8`, `11.6`. The first item is `0`, and each later item appears exactly when its cue begins to be spoken.
- Omit `at` ONLY for an item that is a general summary not tied to any single cue (rare). Do NOT leave `at` out of items just to be safe, and do NOT invent evenly spaced values that no cue supports.
- `at` must be a number ≥ 0 (never a string, never negative, never beyond the scene duration). The example JSON below shows the field shape — replace the demo values with cue-derived ones.
