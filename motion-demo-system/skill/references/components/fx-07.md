# fx-07 - 大标题+多行列表卡片

- Component version: 1
- Use for: Parallel feature or viewpoint cards with 2-4 cards.
- Avoid: Avoid a single narrative and more than 4 cards.
- Motion feel: 外框淡入后标题单独淡入，小卡片逐个浮现（两列网格、每张间隔约 0.4s）。
- Capacity: 2-4 items

## Editable content

Only the following keys may appear in `content`. All style and component layout properties are locked and must not be supplied by an Agent.

- `cards`: array of objects { d: 卡片说明 (string), t: 卡片标题 (string) }; required: yes; default: `[{"d":"小标题1说明放在这里","t":"小标题1"},{"d":"小标题2说明放在这里","t":"小标题2"},{"d":"小标题3说明放在这里","t":"小标题3"},{"d":"小标题4说明放在这里","t":"小标题4"}]`; semantic role: items; constraints: 2-4 items; all listed item fields are required strings.
- `footText`: text; required: yes; default: `"补充说明1234567890"`; semantic role: body; constraints: none beyond the declared type.
- `tagText`: text; required: yes; default: `"顶部标签"`; semantic role: label; constraints: none beyond the declared type.
- `titleText`: text; required: yes; default: `"大标题在此可编辑"`; semantic role: title; constraints: none beyond the declared type.

## Per-item timing (`at`)

Each item in `cards` carries a numeric `at` field — the item's appearance time in **seconds, relative to the scene's earliest cited cue start**. Items appear at their `at` time instead of the default even rhythm.

- **Every item that corresponds to one cited cue MUST get an `at`.** Compute it from the cue start times: `at = (cueStartMs − earliestCitedCueStartMs) / 1000`, rounded to 1 decimal. Include every cue you used in the scene's `sourceCueIds`.
- Worked example: a scene cites cues starting at 9800ms / 15600ms / 21400ms (earliest = 9800) and its cards rows visualize them → `at` values are `0`, `5.8`, `11.6`. The first item is `0`, and each later item appears exactly when its cue begins to be spoken.
- Omit `at` ONLY for an item that is a general summary not tied to any single cue (rare). Do NOT leave `at` out of items just to be safe, and do NOT invent evenly spaced values that no cue supports.
- `at` must be a number ≥ 0 (never a string, never negative, never beyond the scene duration). The example JSON below shows the field shape — replace the demo values with cue-derived ones.
