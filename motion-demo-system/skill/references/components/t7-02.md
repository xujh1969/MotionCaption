# t7-02 - 横向条形对比图

- Component version: 1
- Use for: Horizontal ranking or option comparison with 2-3 bars.
- Avoid: Avoid large datasets, precision analysis, complex axes, and more than 3 bars.
- Motion feel: —
- Capacity: 2-3 items

## Editable content

Only the following keys may appear in `content`. All style and component layout properties are locked and must not be supplied by an Agent.

- `nodes`: array of objects { cat: 类目名称 (string), val: 数值(%) (string) }; required: yes; default: `[{"cat":"CPU占用","val":"62"},{"cat":"内存占用","val":"48"},{"cat":"GPU占用","val":"76"}]`; semantic role: items; constraints: 2-3 items; all listed item fields are required strings.
- `titleText`: text; required: yes; default: `"资源占用对比"`; semantic role: title; constraints: none beyond the declared type.

## Per-item timing (`at`)

Each item in `nodes` carries a numeric `at` field — the item's appearance time in **seconds, relative to the scene's earliest cited cue start**. Items appear at their `at` time instead of the default even rhythm.

- **Every item that corresponds to one cited cue MUST get an `at`.** Compute it from the cue start times: `at = (cueStartMs − earliestCitedCueStartMs) / 1000`, rounded to 1 decimal. Include every cue you used in the scene's `sourceCueIds`.
- Worked example: a scene cites cues starting at 9800ms / 15600ms / 21400ms (earliest = 9800) and its nodes rows visualize them → `at` values are `0`, `5.8`, `11.6`. The first item is `0`, and each later item appears exactly when its cue begins to be spoken.
- Omit `at` ONLY for an item that is a general summary not tied to any single cue (rare). Do NOT leave `at` out of items just to be safe, and do NOT invent evenly spaced values that no cue supports.
- `at` must be a number ≥ 0 (never a string, never negative, never beyond the scene duration). The example JSON below shows the field shape — replace the demo values with cue-derived ones.
